# Telegram Secretary Bot — نظام السكرتير الذكي المتكامل لإدارة حساب تيليجرام

نظام متكامل لإدارة حساب تيليجرام الشخصي وتحويله إلى مساعد سكرتير ذكي يجمع بين إمكانات **Telegram Business API** وتكامل الحساب الشخصي عبر **MTProto (Telethon)**، مع لوحة تحكم عربية تفاعلية بالكامل من داخل تيليجرام ومحمية لمالك النظام فقط.

---

## 1. الوظائف الرئيسية

- **لوحة تحكم عربية تفاعلية (12 قسمًا):** مبنية بالكامل على `Inline Keyboards` ومقيدة بمعرف المالك (`OWNER_ID`).
- **محرك قواعد ردود تلقائية متقدم:** يدعم المحفزات (`first_message`, `keyword`, `regex`, `any`)، الأولويات، التأخير (`Delay`)، فترات الانتظار (`Cooldown`)، والاستثناءات.
- **إدارة القوالب والوسائط والأزرار:** دعم النصوص المنسقة، الصور، الفيديو، المستندات، الرسائل الصوتية، الملصقات، المتغيرات الديناميكية (`{first_name}`, `{username}`, `{date}`, `{time}`)، والمعاينة الحية.
- **نظام حذف الرد السابق واستبداله الذري:** يرسل الرد التلقائي الجديد أولًا، وبعد التأكد من نجاحه يحذف الرد التلقائي السابق فقط، مع قفل مستقل لكل محادثة (`Per-Chat Lock`) وعدم المساس برسائل المستخدم أو الرسائل اليدوية للمالك.
- **بث المجموعات بهوية الحساب الشخصي:** اكتشاف المجموعات، فحص صلاحيات الإرسال الفعلية، تنظيمها في تصنيفات (`Collections`)، وإرسال الحملات باسم وصورة الحساب الشخصي.
- **إدارة الحملات والجدولة وإبطال `run_id`:** حملات فورية، مجدولة، ومتكررة، مع إيقاف فوري لأي تنفيذ قديم عند استبدال الحملة (`run_id invalidation`) واستعادة المهام بعد إعادة تشغيل الخادم.
- **ميزات السكرتير المتقدمة:** ساعات العمل، وضع الغياب (`Away Mode`)، رسائل الترحيب، الردود السريعة، الإشعارات الإدارية، والتقارير الإحصائية (اليومية/الأسبوعية/الشهرية).

---

## 2. المتطلبات التقنية

- نظام التشغيل: **Ubuntu 22.04 / 24.04 LTS** (أو أي توزيعة Linux).
- **Python 3.11+**.
- مدير العمليات **PM2** (للنشر على VPS).
- حساب تيليجرام يدعم **Telegram Business** (لربط البوت بالمحادثات الخاصة).
- بيانات تطبيق تيليجرام (`API_ID` و`API_HASH`) من موقع `https://my.telegram.org`.

---

## 3. طريقة التثبيت والإعداد

```bash
# 1. الدخول إلى مجلد المشروع وإنشاء البيئة الافتراضية
cd Telegram-Secretary-Bot
python3 -m venv venv
source venv/bin/activate

# 2. تثبيت المكتبات المطلوبة
pip install --upgrade pip
pip install -r requirements.txt

# 3. نسخ ملف البيئة وتوليد مفتاح تشفير الجلسة
cp .env.example .env
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

إعداد ملف .env
افتح ملف .env وأدخل القيم الخاصة بك:
 * BOT_TOKEN: توكن بوت الإدارة من @BotFather.
 * OWNER_ID: معرفك الرقمي في تيليجرام.
 * TG_API_ID وTG_API_HASH: من موقع my.telegram.org.
 * SECRET_ENCRYPTION_KEY: مفتاح Fernet الذي قمت بتوليده في الخطوة السابقة.
4. إنشاء بوت الإدارة وربط Telegram Business
 * توجه إلى @BotFather وأنشئ بوتًا جديدًا أو استخدم بوتك الحالي، ثم فعّل Business Mode للبوت من إعدادات @BotFather.
 * من حسابك الشخصي في تطبيق تيليجرام:
   * اذهب إلى الإعدادات (Settings) ⟵ Telegram Business ⟵ البوتات (Chatbots).
   * أضف معرف بوت الإدارة.
   * فعّل صلاحية الرد على الرسائل (Reply to messages) وصلاحية حذف الرسائل الصادرة (Delete sent messages).
5. تفويض الحساب الشخصي (لبث المجموعات)
 * افتح بوت الإدارة وأرسل /start.
 * اختر 1️⃣1️⃣ إعدادات الحساب والتكاملات ⟵ 🔐 ربط / إعادة تفويض الحساب الشخصي.
 * أرسل رقم هاتفك بالصيغة الدولية، ثم أرسل رمز التحقق مفصولًا بمسافات (مثال: 1 2 3 4 5).
 * سيقوم البوت بحذف رسالتك فورًا لحمايتها، ويشفر جلسة Telethon بمفتاح Fernet ويحفظها في قاعدة البيانات.
6. تشغيل الاختبارات (pytest)
source venv/bin/activate
pytest -v

7. النشر على Ubuntu VPS باستخدام PM2
# تشغيل النظام عبر PM2 (بنسخة واحدة محمية بـ PID Lock)
pm2 start ecosystem.config.js

# حفظ القائمة لتعمل تلقائيًا عند إعادة تشغيل الخادم
pm2 save
pm2 startup

# متابعة السجلات الحية
pm2 logs telegram-secretary-bot

8. النسخ الاحتياطي والاستعادة واستكشاف الأخطاء
 * النسخ الاحتياطي الفوري: من لوحة التحكم ⟵ 1️⃣2️⃣ إعدادات النظام ⟵ 💾 إنشاء نسخة احتياطية فورية. تُحفظ النسخ في مجلد ./backups/.
 * فحص سلامة قاعدة البيانات: من قسم إعدادات النظام ⟵ 🩺 فحص سلامة قاعدة البيانات للتأكد من أن Integrity: OK ووضع WAL مفعل.
 * توقف النظام بسبب قفل العملية: إذا توقف الخادم بشكل قسري وبقي ملف ./data/secretary_bot.lock، يتحقق النظام تلقائيًا من رقم العملية (PID) ويتجاوزه إذا لم تكن العملية نشطة.
